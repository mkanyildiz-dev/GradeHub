# Workflow Regeln

## Git & Commits
- **Atomic Commits:** Jede Änderung muss eine in sich geschlossene, funktionale Einheit sein. Keine "Mega-Commits" mit vielen verschiedenen Features.
- **Commit Messages:** Nutze klare, aussagekräftige Nachrichten (vorzugsweise Conventional Commits wie `feat:`, `fix:`, `docs:`).
- **Stabilität:** Der Code muss nach jedem Commit kompilierbar und lauffähig sein.

## Arbeitsweise
- Bevor große Änderungen vorgenommen werden, wird ein Plan erstellt.
- Feedback-Schleifen nach wichtigen Meilensteinen.
